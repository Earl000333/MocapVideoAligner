# 触觉对齐机制说明

> 本文专门说明「动捕-触觉对齐」页的数据约定、对齐机制、界面交互与导出结果。
> 视觉-动捕对齐流程保持独立，字段与导出逻辑不变。

---

## 1. 在整体流程中的位置

完整离线对齐通常分两步：

1. **视觉-动捕对齐**  
   得到 `delta_t`，并导出 `*_aligned.bvh` 等结果。
2. **动捕-触觉对齐**  
   在已对齐动捕的基础上，求解动捕与足底压力之间的时间偏移 `delta_t2`。

软件主窗口使用两个页签：

| 页签 | 目标偏移 | 主要输入 | 主要输出 |
|---|---|---|---|
| 视觉-动捕对齐 | `delta_t` | 四相机 + BVH | `*_aligned.bvh`、`*_alignment.json` 等 |
| 动捕-触觉对齐 | `delta_t2` | 已对齐 BVH + 左右脚压力 | `*_pressure_alignment.json`、Fake 帧 CSV 等 |

硬约束：

- 不改动原有视觉-动捕页的算法、UI 与导出字段。
- 触觉功能以新增页签 + 新增模块方式实现。

## 2. 数据输入

### 2.1 动捕

优先使用视觉-动捕对齐后的 BVH：

```text
sync/output/<session_id>/<session_id>_*_aligned.bvh
```

若尚无对齐结果，页面可能回退到当前会话显示用 BVH，但推荐先完成视觉-动捕对齐。

### 2.2 触觉压力

按优先级加载：

1. **重建触觉目录**（推荐）
2. 相机会话目录中的 `pressure_left.csv` / `pressure_right.csv`

重建目录可在页面中「导入重建触觉数据」指定，默认也可在 `config.py` 的
`DEFAULT_RECONSTRUCTED_TACTILE_ROOT` 配置。

#### 新连续格式（优先）

```text
reconstruction_<timestamp>/
  <date>/<subject>/rec..._<session>/
    pressure_left.csv
    pressure_right.csv
    reconstruction_manifest.csv
```

#### 旧分段格式（兼容）

```text
rec..._<session>/
  pressure_left_t0.csv
  pressure_right_t0.csv
  ...
  reconstruction_manifest.csv
```

常见压力 CSV 列：

```text
frame_idx,t_us,valid_mask,source_frame_idx,source_t_us,1,2,...,48
```

说明：

- `t_us`：时间戳（微秒）。
- `1..48`：传感器通道。
- `valid_mask=1`：原始有效帧。
- `valid_mask=0`：重建 / 插值 / 重采样帧。

### 2.3 粗偏移锚点

若采集目录存在 `meta.json`，会读取时钟信息计算粗偏移 `t_coarse`，
主要用于限制旧机制的搜索窗口；**不是最终 `delta_t2`**。  
缺失时搜索窗口退化为更宽松范围。

### 2.4 质量表与试次跳过

工作区根目录可放置：

```text
missing_pressure_objects.csv
```

关键列：

- `dataset_id`：如 `S5011`、`S13012`
- `quality_class`：
  - `C`：触觉缺失（如单侧缺失）
  - `D`：整组数据未记录

导航规则：

- 「上一试次 / 下一试次」自动跳过 `C` / `D`。
- 「选择批次」仍显示这些试次，但置灰且不可选。
- 重建目录若出现左右脚一侧无有效数值行，也会按缺失（`C`）处理。

标识归一化示例：

- `S1301_2` → `S13012`
- 重建文件夹名 `rec..._S1301_2` → `S13012`

## 3. 两种对齐机制

页面右侧「对齐机制」提供两个互斥按钮，点选后自动重估，选中项高亮。

### 3.1 旧机制：足底贴地曲线互相关

动捕侧：

1. 从 BVH 取左右脚相关关节世界坐标。
2. 取该脚竖直方向最低点高度 `h(t)`。
3. 构造贴地程度曲线：`-h(t)`，再归一化到 `[0,1]`。
4. 值越大表示脚越贴近地面。

触觉侧：

1. 左右脚压力通道总和。
2. 归一化到 `[0,1]`。
3. 不对压力总和做额外时域平滑，避免抹掉着地冲击。

估计：

1. 以 `t_coarse` 为中心，在搜索窗内做归一化互相关。
2. 左右脚分别得到 `delta_t2_left` / `delta_t2_right`。
3. 最终 `delta_t2` 取可用结果的均值。
4. 同步记录峰值高度；左右差异过大或峰值过低时界面给出警告。

旧机制曲线显示：

- 触觉-L / 触觉-R
- 动捕-L / 动捕-R
- 勾选框为成对控制：`左脚 L（触觉+动捕）`、`右脚 R（触觉+动捕）`
- 切换试次时保留勾选状态

### 3.2 新机制：触地事件对齐

旧机制在支撑期曲线易饱和，互相关峰较钝。新机制改为比较**触地时刻**：

1. 动捕侧估计触地 / 加载起始事件。
2. 触觉侧估计压力上升起始事件。
3. 在粗偏移附近匹配事件对。
4. 以匹配事件差的稳健统计量（如中位数）得到 `delta_t2`。
5. 输出匹配数量、离散度、是否可信等诊断信息。

新机制曲线显示：

- 两条总曲线：动捕触地代理、触觉压力总和
- 可用双纵轴避免振幅差异过大
- 标题区显示事件诊断（n / scatter / ok 等）

说明：  
代码中的 `DynamicsVgrfCurveSet` 名称保留了历史痕迹，当前主要用于**显示**两条总曲线；
偏移估计以触地事件匹配为主，而不是整段 CoM 动力学拟合。

## 4. 显示规则

### 4.1 足底热图

- 左右脚压力热图随预览光标更新。
- 当前最近帧若 `valid_mask=1`，显示 `Valid` 标记。

### 4.2 曲线虚实线

针对带 `valid_mask` 的触觉曲线：

| valid_mask | 线型 |
|---|---|
| `1` 原始有效帧 | 实线 |
| `0` 重建/插值/重采样帧 | 虚线 |

### 4.3 预览光标

与视觉页一致：

- 点击曲线跳转
- 按住拖动连续移动
- 同步更新热图、骨架预览与播放位置

## 5. Fake 片段标记

一个完整试次（如 `S501_1`）中可能存在多段需要人工标记的 Fake 区间。

操作：

1. 移动光标到起点 → **记录 Fake 起点**
2. 移动光标到终点 → **记录 Fake 终点**
3. 可重复记录多段
4. **撤销上一段**可取消待定起点或删除最近完成段
5. **导出 Fake 帧 CSV**

时间基准：

- **以左脚离散帧为准**
- 右脚取与该左脚时间最近的一帧

曲线上会显示：

- 绿色竖线：起点
- 蓝色虚线：终点
- 橙色半透明带：已完成片段

### 导出 CSV

默认目录：

```text
sync/output/fake_tactile_csv/<trial>_fake_frames.csv
```

表头仅保留必要字段：

```csv
segment_id,left_frame_idx,left_time_s,right_frame_idx,right_time_s
```

每一行对应一个左脚基准 fake 帧及其最近右脚帧。  
不写摘要行，也不附带来源路径、导出时间等冗余列。

## 6. 对齐结果导出

动捕-触觉对齐导出与视觉页分离，不改写 `*_alignment.json`。

输出目录：

```text
sync/output/<session_id>/
```

常见文件：

```text
<session_id>_pressure_alignment.json
<session_id>_pressure_aligned_curves.csv
<session_id>_pressure_calibration.png
```

### `*_pressure_alignment.json` 主要字段

| 字段 | 含义 |
|---|---|
| `session_id` | 会话编号 |
| `delta_t2` | 最终偏移（秒） |
| `delta_t2_left` / `delta_t2_right` | 左右脚结果（旧机制更有区分意义） |
| `peak_left` / `peak_right` | 互相关峰值等可信度信息 |
| `t_coarse` | 粗偏移 |
| `search_window_ms` | 搜索窗口 |
| `manual_adjusted` | 是否人工微调 |
| `reference_fps` | 参考帧率 |
| `mocap_source_file` | 动捕来源 |
| `pressure_source_file` | 压力来源 |
| `axis_preset` | 坐标预设 |
| `exported_at` | 导出时间 |

### `*_pressure_aligned_curves.csv`

```csv
time_s,mocap_left,mocap_right,pressure_left,pressure_right
```

写入应用 `delta_t2` 后的归一化曲线；某侧缺失时可为空。

## 7. 推荐操作流程

1. 先在「视觉-动捕对齐」完成 `delta_t`，并导出 aligned BVH。
2. 切换到「动捕-触觉对齐」。
3. 确认重建触觉根目录；必要时点击「导入重建触觉数据」。
4. 可选：导入视频-动捕对齐 CSV，用已有偏移辅助初始化。
5. 选择旧机制或新机制，查看自动 `delta_t2`。
6. 用光标、热图与曲线检查；必要时手动微调。
7. 如需标注异常压力段，记录多段 Fake 起终点并导出帧表。
8. 导出压力对齐结果。
